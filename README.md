# The Sughayyr game engine.

**Sughayyr** (from the Arabic word for _'small'_) is a simple game engine written entirely in C11 (for stdatomic.h only, everything else C99). It is meant to be small & performant; it supports huge open-world games even on the weakest graphics hardware. It is highly configurable.

It features an in-house OpenGL 3d graphics engine & a simple but fast physics engine. I wrote it for fun and to learn more about 3d graphics.

## Current state of things.
